WGET-CURL

pjfetch 0.1.0 · section 1 · 2026-10-15

NAME

wget-curl - 多段并发 HTTP(S) 下载器（IDM 风格）

SYNOPSIS

wget-curl [para-jobs= N] [options] url

DESCRIPTION

wget-curl 基于 libpjfetch (3) 下载 HTTP/HTTPS 资源：探测到服务器支持 Range 后切成若干段并行下载（默认 8 段），每段独立重试，中断后可断点续传。服务器不支持 Range、文件过小、或"宣称支持却不兑现"（对 Range 请求返回 200）时，自动退化为单流。

进度显示在 stderr；下载内容写入文件，日志与状态不混入数据流。

FIRST ARGUMENT

para-jobs= N

并行分段数。必须是第一个参数（若存在），N 会被钳到 1..32，默认 8。该参数出现在非首位、或数值非法时为用法错误。首个位置参数若不匹配 para-jobs=, 则视为 URL。

OPTIONS

-O path

输出到精确路径（目录与文件名均以该值为准）。

-P dir

输出到目录前缀，文件名由 URL 或 Content-Disposition 推导。

-c

启用断点续传（默认即开启，此开关为显式冗余）。

--no-resume

关闭断点续传：忽略既有 .part 与 .pjmeta, 从头开始。

--retry N

每段最大重试次数，默认 5。重试采用指数退避（上限 8 秒），并从该段已完成偏移继续。

--timeout S

单次传输的整体超时（秒）。0（默认）表示不限。

--connect-timeout S

连接超时（秒），默认 15。

--low-speed-limit B

低速中止阈值（字节/秒）。配合 --low-speed-time 使用，用于检测"连接已建立但传输停滞"。

--low-speed-time S

上述低速状态需持续 S 秒才中止，默认 20。

-U, --user-agent S

User-Agent 字符串。

--header "K: V"

附加请求头，可重复；多个头以 CRLF 拼接。

--referer S

Referer 请求头。

--proxy S

代理 URL。未指定时沿用 libcurl 的环境变量约定。

--no-check-certificate

跳过 TLS 证书校验（默认校验）。

-q

安静模式：不显示进度与状态行。

-v

详细模式：把 libcurl 的调试输出打到 stderr。

--show-progress / --no-progress

强制开启/关闭进度条（默认为：stderr 是终端且未指定 -q 时开启）。

-h, --help

显示帮助并退出。

--version

显示版本并退出。

EXIT STATUS

0

成功。

1

网络或 HTTP 失败（不可达、超时、4xx/5xx、重试耗尽等）。

2

用法错误（未知选项、缺少 URL、参数非法）。

3

本地 I/O 错误（无法写文件、磁盘满）。

4

不支持的请求（URL 非法、协议不支持）。

5

用户中断（Ctrl+C）。已保存续传状态，可直接 -c 重跑。

FILES

~/.pjfetch/pj-cfg.cnf

全局配置。Apache 风格的 Section-Key-Value； [global] 段内的键取长选项名（如 para-jobs=16, retry=5, user-agent=...）。命令行显式给出的选项覆盖配置值。

~/.pjfetch/pj.ses

下载会话记录（开始/结束各追加一行，含 URL、输出路径、状态、时间戳）。

<输出文件名>.pjfetch.dld

CLI 层控制文件：记录本次的选项快照与状态。成功后删除；失败或中断时保留， -c 重跑时读取校验。

<输出文件名>.part

下载中的工作文件。传输完成后被重命名为最终文件名。

<输出文件名>.pjmeta

续传 sidecar（库层维护）：记录 URL、总长、ETag/Last-Modified 与各段已完成偏移。恢复前会校验 URL、总长、.part 大小与内容标识，任一不符则丢弃并重新开始。下载成功后自动删除。

EXAMPLES

8 段并行下载：

wget-curl para-jobs=8 -O archive.tar.gz https://example.com/archive.tar.gz

中断后继续（Ctrl+C 退出码 5 之后）：

wget-curl -c -O archive.tar.gz https://example.com/archive.tar.gz

经代理下载并带自定义头：

wget-curl --proxy http://127.0.0.1:8080 \
          --header "Authorization: Bearer ..." \
          https://example.com/data.bin

NOTES

输出文件名推导：取 URL 末段（去 query/fragment）→ percent-decode → 清洗 Windows 非法字符与控制符 → 保留设备名（CON/NUL/COM1 等）追加下划线 → 限长 200 字节并保留扩展名。若未指定 -O, 且响应带 Content-Disposition，则按其中文件名重命名结果。
