LIBPARAJOBS

pjfetch 0.1.0 · section 3 · 2026-10-15

NAME

libparajobs - 基于 libgo 协程的并行任务引擎（C ABI）

SYNOPSIS

#include <parajobs/parajobs.h>

pjb_engine_t pjb_engine_create(int32_t min_threads, int32_t max_threads);
void pjb_engine_destroy(pjb_engine_t eng);
pjb_status pjb_engine_drain(pjb_engine_t eng, uint32_t timeout_ms);
int32_t pjb_engine_concurrency(pjb_engine_t eng);

pjb_job_id pjb_submit(pjb_engine_t eng, pjb_job_fn fn, void *ud,
                       pjb_job_done_cb on_done, void *done_ud);
pjb_status pjb_job_cancel(pjb_engine_t eng, pjb_job_id id);
int32_t pjb_job_canceled(pjb_engine_t eng, pjb_job_id id);
pjb_status pjb_job_wait(pjb_engine_t eng, pjb_job_id id, uint32_t timeout_ms);
int32_t pjb_job_is_done(pjb_engine_t eng, pjb_job_id id);

void pjb_sleep_ms(pjb_engine_t eng, uint32_t ms);
const char *pjb_version(void);

DESCRIPTION

libparajobs 把 libgo (3) 的协程调度封装为纯 C ABI 的通用并行任务引擎：提交、协作式取消、等待与排空。公共头不泄漏 libgo 或 C++ 类型。

Windows 上 libgo 用 Win32 Fiber，并在进程级挂钩 winsock 的 select / recv / send / accept 等函数，使阻塞式 socket 调用在协程内自动挂起——故任务体可直接使用阻塞网络 API。

TYPES

pjb_engine_t

不透明引擎句柄。每个引擎持有自己的 libgo 调度器。

pjb_job_id

任务标识（自 1 递增）； PJB_INVALID_JOB 为 0，表示无效。

pjb_status

状态码： PJB_OK, PJB_ERR_INVALID_ARG, PJB_ERR_NOT_INITIALIZED, PJB_ERR_TIMEOUT, PJB_ERR_CANCELED, PJB_ERR_INTERNAL.

pjb_job_fn

typedef void (*pjb_job_fn)(void *userdata); 在调度线程上执行的任务体。

pjb_job_done_cb

typedef void (*pjb_job_done_cb)(pjb_job_id id, void *ud);
任务结束后恰好触发一次（取消未启动也触发）。回调内禁止对同一引擎调用 pjb_engine_drain 或 pjb_engine_destroy，否则自等死锁。

RETURN VALUES

pjb_engine_create

成功返回非空句柄； min_threads <= 0 取硬件并发数； max_threads <= 0 时取 min_threads.

pjb_submit

成功返回非零任务 id；引擎无效或参数非法返回 PJB_INVALID_JOB.

pjb_job_wait

timeout_ms 为 0xFFFFFFFF 表示无限等待；超时返回 PJB_ERR_TIMEOUT, 未知任务 id 返回 PJB_ERR_INVALID_ARG.

pjb_job_is_done, pjb_job_canceled

返回 1/0；未知 id 或引擎无效返回 -1。

pjb_engine_concurrency

返回调度器最大线程数；引擎无效返回 0。

pjb_engine_drain

等待未完成任务数归零；超时返回 PJB_ERR_TIMEOUT.

THREADING

创建与销毁应在单一线程进行。 pjb_submit, pjb_job_wait, pjb_job_cancel, pjb_job_is_done 与 pjb_job_canceled 可从任意线程调用（包括从其他任务体内）。

pjb_engine_destroy 会先排空全部任务（含 on_done 回调）再停止调度器；该操作不可逆，销毁后引擎不可再用。 pjb_job_wait 会阻塞调用线程，不应在协程内使用。

NOTES

pjb_sleep_ms 在调度线程内等价于协程睡眠（让出 fiber）；在普通线程上为标准库睡眠。

取消是协作式的：置位取消标志后，任务体需自行轮询 pjb_job_canceled 并尽早返回。

EXAMPLE

static void work(void *ud) {
        pjb_engine_t e = (pjb_engine_t)ud;
        for (int i = 0; i < 10; ++i) {
                if (pjb_job_canceled(e, PJB_INVALID_JOB)) return;
                /* ... do work ... */
                pjb_sleep_ms(e, 10);
        }
}

pjb_engine_t e = pjb_engine_create(4, 8);
pjb_job_id id = pjb_submit(e, work, e, NULL, NULL);
pjb_job_wait(e, id, 0xFFFFFFFFu);
pjb_engine_destroy(e);
